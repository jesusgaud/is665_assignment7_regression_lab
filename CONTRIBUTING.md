# Contributing

For normal assignment use, do not edit source code. Run `START_ASSIGNMENT.bat` and export the result package.

For code changes:

1. Create a feature branch from `main`.
2. Run `ruff check .`, `mypy src`, and the pytest coverage command.
3. Commit the change with a clear message.
4. Push the feature branch and open a pull request.
5. Merge only after CI passes.
